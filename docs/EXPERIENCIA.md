# Texto desde la cámara

Extrae texto de una fotografía tomada con la cámara.

- Entrada: Foto de texto impreso.
- Resultado: Texto reconocido mediante OCR.
- Tecnología: Tesseract · OpenCV

## Uso

Selecciona el filtro en el panel lateral, habilita la cámara y toma una foto con el texto enfocado.

## Límites

La iluminación, el enfoque y el contraste afectan el reconocimiento. Revisa manualmente el texto extraído.
